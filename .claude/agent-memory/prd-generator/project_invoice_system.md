노션을 단일 데이터 소스로 사용하는 견적서 웹 시스템 개발 중.

**Why:** 프리랜서/소규모 사업자가 별도 DB 없이 노션만으로 견적서를 관리하고, 클라이언트에게 공유 URL과 PDF를 제공하기 위함.

**How to apply:**
- 별도 DB 제안 금지 (노션이 SSOT)
- 웹에서 견적서 편집 기능은 scope 외 (노션에서만 작성)
- MVP 우선: 인증, 이메일 발송, 결제 연동은 Phase 3 이후
- PDF 생성은 Puppeteer 기반으로 결정 (Vercel 제한 시 대안 검토 필요)
